# Changelog

All notable changes to the **DevIntel AI** VS Code extension will be documented here.

## [1.0.0] — 2026-03-06

### Added
- **Sidebar AI Chat** — streaming RAG-based chat via the DevIntel API with repository selector and per-message cost display
- **Review Current File** — right-click context menu command to analyse the active editor file
- **Ask AI** command — Command Palette shortcut that focuses the sidebar chat
- **Secure token storage** — JWT stored in VS Code SecretStorage (OS keychain)
- **Configurable API URL** — `devintel.apiBaseUrl` workspace setting
